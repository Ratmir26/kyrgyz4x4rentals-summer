## Что было сделано

### Исправление отображения фотографий

**Проблема:** При вставке фото в карточку изображение отображалось криво — сжималось, приближалось, нарушало вёрстку.

**Решение:**
- Заменены SVG-иллюстрации на реальные фотографии в 5 карточках
- Добавлен класс `.car-photo` с корректным CSS:
  - `object-fit: cover` — заполнение контейнера без искажений
  - `width: 100%; height: 100%` — адаптивность
  - `object-position: center` — центрирование
  - `transition: transform 0.5s ease` — плавный hover-эффект
