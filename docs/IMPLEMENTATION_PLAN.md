## Что было сделано

### Исправление отображения фотографий

**Проблема:** При вставке фото в карточку изображение отображалось криво — сжималось, приближалось, нарушало вёрстку.

**Решение:**
- Заменены SVG-иллюстрации на реальные фотографии в 5 карточках
- Добавлен класс `.car-photo` с корректным CSS:
  - `object-fit: cover` — заполнение контейнера без искажений
  - `width: 100%; height: 100%` — адаптивность
  - `object-position: center` — центрирование
  - `transition: transform 0.5s ease` — плавный hover-эффект

## Текущий план (октябрь 2026)

1. **Фикс калькулятора (внедрено):** `calculateTotal` только читает поле через `getDaysForCalc()`; минимум 5 — на change/blur (`clampDaysInput`) и перед WhatsApp.
2. **Отзывы + регистрация (Supabase, бесплатный тариф):** вход по email+пароль; отзыв = имя из аккаунта + текст + оценка 1–5 + одно фото по желанию; публикация только после одобрения владельцем (переключатель в табличке Supabase, без админки в MVP); подтверждение email выключено, от спама защищает одобрение. Нужен Supabase-проект + anon-ключ от владельца репозитория.
3. **Решения владельца (заморожено, не трогать):** модалка договора всегда EN; смешанные RU/EN-формулировки Terms; латиница зон.

## Известные ограничения

- Рантайм в одном файле; исходник текстов — `locales/*.json` + `build.py`
- Фотографии в формате JFIF — для веба лучше использовать WebP или JPEG для меньшего веса
- Нет серверной части — бронирование через WhatsApp; отзывы потребуют внешний сервис (Supabase)
