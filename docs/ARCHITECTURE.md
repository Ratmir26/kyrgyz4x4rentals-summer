# Архитектура проекта

## Обзор

Kyrgyz4x4rentals — одностраничный статический сайт без серверной части. Рантайм — один файл `index.html` (вся разметка, стили и JS инлайн). Исходник текстов интерфейса — `locales/ru.json` + `locales/en.json`, словарь вшивается в `index.html` сборкой `python build.py`.

## Компоненты

### Карточка автомобиля (`.car-card`)

```html
<div class="car-card">
    <div class="car-image-container">
        <span class="car-badge">Название</span>
        <img class="car-photo" src="img/photo.jfif" alt="...">
    </div>
    <div class="car-info">
        <h3 class="car-title">Название</h3>
        <div class="car-specs-list">
            <div class="spec-item">...</div>
        </div>
        <a href="#pricing" class="btn btn-primary">Забронировать</a>
    </div>
</div>
```

### Калькулятор (`.calculator-box`)

- Выбор автомобиля (select)
- Количество дней (number input, min 5)
- Количество путешественников (select: 2 или 3+)
- Автоматический расчёт стоимости
- Отправка в WhatsApp

## Технические решения

### CSS-переменные

Все цвета и размеры вынесены в CSS-переменные в `:root`. Тёмная и светлая темы переключаются через атрибут `data-theme` на `<html>`.

### Адаптивность

- Desktop: сетка карточек 3 колонки (auto-fit, minmax 320px)
- Tablet (< 992px): тарифы и контакты в 1 колонку
- Mobile (< 768px): мобильное меню, уменьшенные размеры

### Локализация

Источник правды — `locales/ru.json` + `locales/en.json` (паритет ключей обязателен). `python build.py` проверяет паритет ru/en и покрытие всех `data-lang`, затем вписывает объект `translations` в `index.html` между маркерами `/*__I18N_BEGIN__*/` / `/*__I18N_END__*/` (сгенерированный блок руками не правится). Переключение языка заменяет содержимое элементов с атрибутом `data-lang`; выбор сохраняется в `localStorage (k4x4-lang)` и применяется при загрузке. Договор аренды — всегда на английском по требованию владельца, ключей не имеет. Вайтлист исключений (не переводится): имена Toyota/Lexus, единицы 4.7L/4WD/€, мессенджеры, топонимы запретных зон.

## Файловая структура

```
Kyrgyz4x4rentals/
├── index.html          # Рантайм сайта (HTML + CSS + JS, i18n-блок сгенерирован)
├── locales/
│   ├── ru.json         # Русские строки (источник правды)
│   └── en.json         # Английские строки (источник правды)
├── build.py            # Валидация ru/en + вшивание словаря в index.html
├── img/                # Локальные изображения (JFIF)
├── docs/               # Документация проекта
└── .opencode/          # Оркестрация: skill site-orchestrator + 6 ролей
```

## Производительность

- Минимальное количество HTTP-запросов
- CSS и JS инлайн в рантайме (на этапе разработки есть `locales/*.json` + `build.py`)
- Иконки через CDN Font Awesome
- Шрифты с `preconnect` для ускорения загрузки
